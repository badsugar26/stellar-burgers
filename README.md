# Stellar Burger — космическая бургерная

## Описание проекта

Stellar Burger — это одностраничное приложение (SPA) для заказа бургеров в «космической» стилистике. Пользователи могут собирать бургер из ингредиентов, оформлять заказы и отслеживать их статус в реальном времени. Проект демонстрирует навыки работы с React, Redux, роутингом и WebSocket-соединениями.

**Ключевые особенности:**

- Сборка бургера из ингредиентов с перетаскиванием (drag-and-drop)
- Лента заказов с обновлением в реальном времени через WebSocket
- Авторизация и защищённые маршруты (личный кабинет, история заказов)
- Двойной режим отображения: модальное окно + отдельная страница (для ингредиентов и заказов)
- Редактирование профиля пользователя с умными кнопками «Сохранить»/«Отмена»
- Адаптивная вёрстка под мобильные устройства и десктопы

**Стек технологий:**

- React 18 — библиотека для построения интерфейсов
- Redux Toolkit — управление глобальным состоянием (слайсы, createAsyncThunk)
- React Router DOM v6 — маршрутизация и защита маршрутов
- WebSocket — реальное время для ленты и истории заказов
- CSS Modules / UI-компоненты — стилизация
- API — взаимодействие с бэкендом (ингредиенты, заказы, авторизация)

## Выводы по результатам проекта

В ходе выполнения проектной работы были достигнуты следующие результаты:

1. **Реализована полноценная архитектура на Redux Toolkit**. Созданы слайсы для пользователя, ингредиентов, конструктора бургера и заказов. Асинхронные запросы к API выполнены через `createAsyncThunk`, что обеспечивает предсказуемое управление состоянием загрузки и ошибок.

2. **Настроена сложная маршрутизация с защитой приватных страниц**. Реализованы публичные маршруты (конструктор, лента заказов) и приватные (профиль, история заказов). Неавторизованные пользователи перенаправляются на страницу входа при попытке доступа к защищённым маршрутам.

3. **Внедрено обновление заказов в реальном времени через WebSocket**. Лента заказов (`/feed`) и история заказов в личном кабинете (`/profile/orders`) автоматически получают новые заказы без перезагрузки страницы. Отображаются статусы заказов («Готовится», «Выполнен», «Отменён») и общая статистика (количество заказов за всё время и за сегодня).

4. **Реализован паттерн «модалка + страница»**. При клике на ингредиент или заказ открывается модальное окно с деталями, а в адресной строке меняется URL. При прямом переходе по этому URL открывается полноценная страница — это улучшает SEO и позволяет делиться ссылками.

5. **Создан личный кабинет с редактированием профиля**. Данные пользователя подставляются в форму из хранилища. При редактировании появляются кнопки «Сохранить» и «Отмена». Отмена возвращает исходные значения, сохранение отправляет PATCH-запрос на API.

6. **Обеспечена адаптивность интерфейса**. Приложение корректно отображается на экранах от 320px до 1920px и выше, с сохранением всех функций и читаемостью текста.

## Инструкция по развёртыванию и системные требования

### Системные требования

- Node.js версии 16 или выше
- npm версии 8 или выше (или yarn/pnpm)
- Современный браузер с поддержкой WebSocket и ES6

**Рекомендованные браузеры:** Google Chrome (версия 90+), Mozilla Firefox (версия 88+), Safari (версия 15+), Edge (версия 90+)

### Инструкция по запуску

**1. Клонировать репозиторий**

git clone <url-репозитория>

**2. Перейти в директорию проекта**

cd stellar-burger

**3. Установить зависимости**

npm install

или

yarn install


**4. Запустить проект в режиме разработки**

npm run start

или

yarn start

**5. Сборка для продакшена**

npm run build

## Этапы работы:

1. Разверните проект и ознакомьтесь с кодом. Все необходимые вам компоненты уже созданы и лежат в папке `src/components`

2. Настройте роутинг.

3. Напишите функционал запросов данных с сервера, используя `Redux` и глобальный `store`. Сами "ручки" уже прописаны и лежат в `utils/burger-api.ts`

4. Настройте авторизацию и создайте защищённые роуты.

## Важно:

Для корректной работы запросов к серверу необходимо добавить переменную BURGER_API_URL в окружение. Сама ссылка находится в файле `.env.example`.
